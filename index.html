FAQ

Questions about our AI-powered tools

Are RanBOT Labs’ tools free to use?

Yes, all products are free — no subscriptions or paywalls.

Do I need an account?

No account needed for most tools. RanBOT AI Summarizer is the one exception — it requires you to configure your own OpenAI API key in the extension settings.

Which browsers are supported?

The four extensions (RanBOTer, Nexus Tab, Bookmark Dashboard, RanBOT AI Summarizer) are built for Chrome. Most other products are web apps that work in any modern browser. NLM Unwatermark is a Python CLI for PDF, PPTX, and image files.

How does the AI-powered extraction work?

Tools like RanBOTer use AI/ML to parse and normalize raw web content into structured data; RanBOT AI Summarizer calls the OpenAI API directly to summarize GitLab issues.

Is RanBOT Labs open source?

Yes, every product ships with public source on GitHub.

Where can I get help or report an issue?

Open an issue on the relevant product’s GitHub repo, or reach out via the email in the footer.
